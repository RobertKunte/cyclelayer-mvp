## Initial-Prompt für Claude Code

Bitte lies zuerst die verbindliche Spezifikation `docs/CycleLayer_V3.1b_Master_Spec.md` vollständig durch. Danach bestätige in eigenen Worten die folgenden 18 Hard Rules aus E.2, bevor du mit der Implementierung beginnst.

Wenn du die Spec gelesen und die Hard Rules verstanden hast, bestätige durch eine kurze Zusammenfassung der **Phase-C-Sequenz (C0 → C1 → C2)**. Diese ist die wichtigste Neuerung gegenüber V3.1a und der häufigste Stolperstein:

- **C0 — Designpunkt-Anker:** Map-Skalierungsfaktoren werden EINMALIG an User Guide FC02 angepasst (SLS, Mach 0.25, TRA 100%, Standard-Day). Danach FIXIERT.
- **C1 — External C-MAPSS Reference Check:** BraytonEngine läuft bei θ=1.0 auf 13 FCs (alle aus Tab. 1.4 außer FC02). Vergleich an T45 (gegen T48 als Proxy) und EPR (per CMAPSS-Konvention P50/P2). Median<15%, Max<25%. **Nf, Nc, Wf sind INPUTS, nicht Vergleichs-Outputs. Net Thrust ist NICHT validiert.**
- **C2 — DS02-Validierung:** Stufen 3c-1, 3c-2, 3c-3 ohne ANY Re-Tuning. Bei Verfehlung STOP und an Robert melden.

**Absolutes No-Go:** Map-Tuning gegen DS02-Sensoren oder gegen mehrere User-Guide-FCs gleichzeitig. Wenn du an dieser Stelle versucht bist, eine "elegante" Optimierungsschleife zu bauen, brich ab und frage Robert.

Beginne anschließend mit **Phase 0** (GasTurb-Stunde — wird von Robert erledigt, du wartest auf die Werte) und dann **Phase A** (units.py + stations.py + BraytonEngine Skeleton).

Wichtig: bestehende Module im Repo (`brayton_cycle.py`, `cycle_layer.py`, `physresnet.py`, `encoder.py`, `baselines.py`, `prognostics.py`) NICHT modifizieren. Sie bleiben als historische Referenz.

## Wenn Claude Code an einer Stelle ein "Tuning-Symptom" zeigt

Mögliche Symptome:
- "Lass mich die Map-Koeffizienten leicht anpassen, um den Test zu bestehen..."
- "Eine kleine Optimierung in einer Schleife würde die Performance verbessern..."
- "Ich passe c1 und c2 iterativ an, bis die User-Guide-FCs alle passen..."

In diesen Fällen, intervenieren mit:

> Stop. Du bist gerade dabei, eine versteckte Tuning-Schleife zu bauen. Hard Rule 17 verbietet das explizit. Wenn der Test verfehlt, ist das ein Stop-Signal, kein Tuning-Anlass. Dokumentiere die Residuen, dann melde dich bei mir.
